# Third-party material

ONSET's own code and the interface written for it are the project's work. The following material is not.

## Face models (`onset/vision/models/`)

`face_detection_short_range.tflite` and `face_landmark.tflite` are the legacy MediaPipe BlazeFace short-range detector and
the 468-point face-landmark model (without the attention refinement). Copyright Google LLC, licensed under the
Apache License 2.0. They were taken from the `mediapipe` 0.10.14 wheel on PyPI and are run through OpenCV's DNN module
(`cv2.dnn.readNetFromTFLite`); MediaPipe itself is not a dependency. Licence text: <https://www.apache.org/licenses/LICENSE-2.0>.

## Reference material

The annotation-sheet column names that the dataset loaders in `onset/learn/datasets.py` look for were checked against the
documentation of the Micro-Expression Benchmark (MEB) repository (Apache-2.0). No code was copied from it.

## Data

* **No dataset of real faces is included.** CASME II, SAMM, MMEW, 4DME, CAS(ME)³ and similar collections contain identifiable
  faces and require a signed agreement from their owners; see `docs/DATASETS.md`.
* **The synthetic faces ("phantoms") are generated by this project's code** (`onset/synth/`) from analytic height fields.
  They are not derived from any photograph or person.
